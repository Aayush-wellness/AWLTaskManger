## 💡 Common Tasks

### Find a Specific Project
1. Type project name in search box
2. Results filter instantly
3. Click to edit or delete

### Review Last Week's Work
1. Click "Filter by Period"
2. Select "Last 7 Days"
3. See only last week's entries

### View Entries Chronologically
1. Click "Sort By"
2. Select "Oldest First"
3. Entries arranged in order

### Browse All Entries
1. Keep "All Time" filter
2. Use page numbers to navigate
3. Click page to jump

## 📊 Stats Bar

```
📊 Total: 87 entries
🔎 Showing: 12 entries
📄 Page 2 of 3
```

- **Total**: All entries in system
- **Showing**: After applying filters
- **Page**: Current page number

## 🎮 Controls

### Search Box
- Type to search
- Case-insensitive
- Searches names & descriptions

### Period Dropdown
- All Time (default)
- Today
- Last 7 Days
- Last 30 Days

### Sort Dropdown
- Newest First (default)
- Oldest First
- Alphabetical

### Pagination
- ← Previous (disabled on page 1)
- [1] [2] [3] ... (page numbers)
- Next → (disabled on last page)

## 🔄 Filter Combinations

### Search + Date
```
Search: "Project A"
Date: "Last 7 Days"
↓
Entries from last 7 days with "Project A"
```

### Date + Sort
```
Date: "Last 30 Days"
Sort: "Alphabetical"
↓
Last 30 days sorted A-Z
```

### All Three
```
Search: "Alpha"
Date: "Last 7 Days"
Sort: "Oldest First"
↓
Last 7 days with "Alpha", oldest first
```

## 📞 Quick Help

**Search not working?**
- Check project names exist
- Try different keywords
- Clear search and retry

**Filters not combining?**

- Check if data exists for combination
- Try removing one filter

- Need more than 10 entries
- Try removing filters
- Check data loaded

**Performance issues?**
- Refresh page
- Clear browser cache
- Check internet connection
